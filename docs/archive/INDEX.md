# Archived root documents

These files sat at the repository root until US-396 (2026-09). They are status reports, plans, audits and setup notes from earlier phases of Brikly; most describe work that has since shipped, been replaced or been dropped, and several describe systems that no longer exist (Expo as the iOS app, multi-site/`site_id` tenancy, Make.com automation). Read them as history, not instructions. Current docs live in `docs/`; the canonical rollback procedure is `docs/RUNBOOK_ROLLBACK.md`.

Links between these files were written when they sat at the root, so relative links between two archived files still resolve; links from them to `src/`, `supabase/` or `scripts/` do not.

Credential values were redacted on the move from `README-MCP.md` and `AUTH_SETUP_DOCUMENTATION.md` (Supabase anon JWTs) and from `COMPLETE_AUTOMATION_DEPLOYMENT.md`, `DEPLOY_BLOG_AUTOMATION.md` and `MAKE_COM_QUICK_REFERENCE.md` (the blog automation `x-api-key`). The values remain in git history.
