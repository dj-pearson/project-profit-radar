## Consolidated Patterns

### Android Project Structure
- Android project initialized via Capacitor 7.4.4 at `android/`
- Main activity: `android/app/src/main/java/com/builddesk/app/MainActivity.java`
- Manifest: `android/app/src/main/AndroidManifest.xml`
- Build config: `android/app/build.gradle` (app-level), `android/variables.gradle` (SDK versions)
- ProGuard: `android/app/proguard-rules.pro`
- Resources: `android/app/src/main/res/` (values, xml, drawable, mipmap)
- App ID: `com.builddesk.app`
- Target SDK: 35, Min SDK: 23

### Capacitor Configuration
- Config file: `capacitor.config.ts`
- Web output dir: `dist-mobile` (built by `vite.config.mobile.ts`)
- Build command: `npm run build:mobile` then `npx cap sync android`
- Android scheme: https, hostname: app.build-desk.com
- Plugins: Camera, Geolocation, PushNotifications, LocalNotifications, Preferences, Network
- BiometricAuth configured in capacitor.config.ts

### Mobile Build Pipeline
- Mobile Vite config: `vite.config.mobile.ts` (separate from web)
- Defines `__MOBILE_BUILD__` flag for runtime detection
- Target: es2020 for broader device compatibility
- Output: `dist-mobile/` directory
- Scripts: `npm run build:mobile:android` (build + cap sync)

### Security Infrastructure (Web)
- Comprehensive security at `src/lib/security/` (sanitize, CSRF, SSRF, rate limiting, etc.)
- Auth: Supabase Auth with JWT, MFA/TOTP, biometric hooks
- Session management: 3 concurrent sessions max, 30min inactivity timeout
- Device trust: fingerprinting + trusted device tracking
- File upload validation: MIME + extension allowlist
- Input sanitization: multi-layer XSS prevention

### Known Gaps (Pre-Audit) — RESOLVED items marked [DONE]
- [DONE] No network_security_config.xml (HTTPS not enforced at Android level)
- [DONE] Only INTERNET permission declared (missing Camera, GPS, etc.)
- [DONE] ProGuard disabled (minifyEnabled=false)
- [DONE] android:allowBackup=true (data leakage risk)
- [DONE] No deep linking / OAuth callback intent filters
- Default Capacitor placeholder icons (not BuildDesk branded)
- [DONE] No foreground service for background GPS tracking
- No Android-specific back button handling

## Completed Work

### AA-001: Network Security Configuration [DONE]
- Created `android/app/src/main/res/xml/network_security_config.xml`
- HTTPS-only enforcement (cleartextTrafficPermitted=false)
- Certificate pinning for *.build-desk.com and *.supabase.co
- Debug overrides for localhost/emulator development
- Referenced in AndroidManifest.xml via android:networkSecurityConfig

### AA-002: Android Permissions [DONE]
- Added 17 permissions to AndroidManifest.xml:
  - Network: INTERNET, ACCESS_NETWORK_STATE
  - Camera: CAMERA
  - Location: ACCESS_FINE_LOCATION, ACCESS_COARSE_LOCATION, ACCESS_BACKGROUND_LOCATION
  - Foreground service: FOREGROUND_SERVICE, FOREGROUND_SERVICE_LOCATION
  - Notifications: POST_NOTIFICATIONS, VIBRATE, RECEIVE_BOOT_COMPLETED, WAKE_LOCK
  - Biometric: USE_BIOMETRIC, USE_FINGERPRINT
  - Storage: READ_MEDIA_IMAGES, READ_EXTERNAL_STORAGE (maxSdkVersion=32)
- Added 5 uses-feature declarations (camera, autofocus, location, GPS, fingerprint)

### AA-003: ProGuard Rules [DONE]
- Enabled minifyEnabled=true and shrinkResources=true in release buildType
- Updated proguard-rules.pro with rules for:
  - Capacitor core (BridgeActivity, Bridge, Plugin, JSObject, etc.)
  - WebView JavaScript interfaces
  - All Capacitor plugins (camera, geolocation, push, notifications, etc.)
  - AndroidX and biometric APIs
  - Firebase/GMS for push notifications
  - Serialization/Gson
  - Log.d/Log.v stripping in release
  - Source file attributes kept for Sentry crash reporting

### AA-004: AndroidManifest Hardening [DONE]
- Set android:allowBackup=false (prevents ADB data extraction)
- Set android:fullBackupContent=false
- Set android:usesCleartextTraffic=false (belt-and-suspenders with network_security_config)
- Set android:hardwareAccelerated=true (WebView performance)
- Created `android/app/src/main/res/xml/data_extraction_rules.xml` (deny-all for cloud + device transfer)
- Added WebView Safe Browsing meta-data (EnableSafeBrowsing=true, MetricsOptOut=true)
- Added deep linking intent filters for https://app.build-desk.com and com.builddesk.app:// OAuth
- Added LocationTrackingService foreground service for background GPS tracking
- Created `android/app/src/main/java/com/builddesk/app/LocationTrackingService.java`
